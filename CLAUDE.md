# Проект: предсказание оценки и цены вина по описанию сомелье

Итоговый проект по курсу NLP.

## Задача
По тексту дегустационной заметки предсказать оценку вина (80–100 баллов) и цену.
Исследовательский вопрос: насколько хорошо оценку и цену можно предсказать только по тексту
и насколько помогает добавление метаданных (страна, сорт, регион).

## Данные
Wine Reviews, Kaggle: https://www.kaggle.com/datasets/zynicide/wine-reviews
Файл winemag-data-130k-v2.csv, около 130 тыс. отзывов Wine Enthusiast.
Колонки: description, points, price, country, province, region_1, variety, winery, taster_name, title.

## Подготовка данных
- удалить дубликаты по description, чтобы одинаковые тексты не попали в train и test
- удалить строки без price, цену логарифмировать
- одно фиксированное разбиение train/val/test 80/10/10, seed=42, сохранить в data/processed
- отдельная подвыборка как в статье IACIS 2022: 12 стран, 26 сортов, 12 дегустаторов, строки с ценой

## Эксперименты
1. Предсказание средним
2. Только метаданные + CatBoost
3. TF-IDF + Ridge
4. Эмбеддинги текста (sentence-transformers) + CatBoost: только текст и текст + метаданные
5. Дообучение RoBERTa-base с регрессионной головой: только текст
6. То же, но метаданные добавлены в текст: "Country: ... Variety: ... Description: ..."
7. Сравнение с previous art: R² на подвыборке IACIS (у них 0.593)
8. Классификация на 2 класса (90+ / 80–89) и 4 класса (80–84, 85–89, 90–94, 95–100),
   ориентир: BERT из Journal of Wine Economics 2022 (89% и 82% accuracy)
9. SHAP-интерпретация и анализ ошибок

Метрики: RMSE, MAE, R² для оценки; MAE и R² по log(price) для цены.
