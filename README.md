# Wine Reviews NLP

Итоговый проект по курсу NLP: **предсказание оценки вина (80–100 баллов) и его цены по тексту дегустационной заметки сомелье**.

**Исследовательский вопрос:** насколько хорошо оценку и цену можно предсказать только по тексту и насколько помогает добавление метаданных (страна, сорт, регион)?

**Данные:** [Wine Reviews (Kaggle, zynicide/wine-reviews)](https://www.kaggle.com/datasets/zynicide/wine-reviews), файл `winemag-data-130k-v2.csv`: около 130 тыс. отзывов Wine Enthusiast.


## Подготовка данных

- Удаляются дубликаты по `description`, чтобы одинаковые тексты не попали и в train, и в test.
- Удаляются строки без `price`. Цена логарифмируется.
- Используется одно разбиение train/val/test **80/10/10** с `seed=42` (89 253 / 11 157 / 11 157 отзывов), сохранённое в `data/processed/`.
- Отдельно собирается подвыборка как в статье IACIS 2022: 12 стран, 26 сортов, 12 дегустаторов, только строки с ценой.
  Точных списков из статьи нет, поэтому берутся самые частые категории. Строки подвыборки остаются в своей части основного разбиения.

В экспериментах 5–6 одна модель предсказывает оба таргета сразу: голова с двумя выходами, таргеты стандартизованы, лосс равен сумме MSE.

Ноутбуки содержат только эксперименты. Весь общий код вынесен в `src/`.
Не коммитятся: данные, эмбеддинги и SHAP-кэш (`data/processed/`), веса моделей (`models/`), предсказания на test (`results/predictions/`).

## Как запустить

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# torch с поддержкой CUDA (нужна для ноутбуков 03–05; RTX 50xx требует CUDA 12.8+)
pip install --force-reinstall --no-deps torch --index-url https://download.pytorch.org/whl/cu130

python data/download.py          # нужен Kaggle API токен (~/.kaggle/kaggle.json)
jupyter notebook notebooks/
```

Ноутбуки выполняются по порядку. При первом вызове `load_splits()` разбиение сохраняется в `data/processed/`, и дальше все ноутбуки используют его.
Ноутбук 05 использует предсказания и чекпойнты, сохранённые ноутбуками 02–04.

Трансформеры обучались локально на NVIDIA RTX 5060 (8 ГБ): bf16 autocast, batch 32, `max_length=192`, 3 эпохи, пик памяти ~4.4 ГБ.

## Выводы

**Ответ на исследовательский вопрос.**
- **Оценка хорошо предсказывается по одному тексту:** дообученная RoBERTa даёт R² 0.77 (RMSE 1.48 балла). Метаданные добавляют немного: R² 0.81.
- **Цена по тексту предсказывается плохо** (R² 0.56) и определяется в основном происхождением вина: одни метаданные дают 0.67, текст с метаданными 0.71.

**Что работает.**
- **Дообучение решает.** Эмбеддинги sentence-transformers без дообучения проигрывают даже TF-IDF + Ridge (R² 0.62 против 0.71 по оценке): универсальный эмбеддинг сглаживает отдельные оценочные слова. Дообученная RoBERTa обходит TF-IDF на 0.06 R².
- **Метаданные удобно передавать прямо в тексте.** Префикс `Country: ... Taster: ... Description: ...` работает не хуже, чем CatBoost с категориальными признаками, и даёт лучший результат по обоим таргетам.

**Previous art.**
- Результат IACIS 2022 (R² 0.593) превзойдён уже TF-IDF + Ridge (0.702), RoBERTa даёт 0.76–0.81. Наши модели обучены на полном train, то есть на большем объёме данных, чем у авторов.
- До Journal of Wine Economics не хватает 2.7 п.п. (2 класса) и 3.4 п.п. (4 класса) по тексту. Отдельный классификатор не лучше классов из регрессии, так что дело не в подходе. Одна из возможных причин — протокол: мы удаляем дубликаты описаний (у 15% строк исходных данных есть точная копия текста), что убирает утечку между train и test.

**Интерпретация (SHAP) и ошибки.**
- **Повышают оценку:** оценочные слова (*lovely, complex, delicious*), структура (*structured, long, silky*) и потенциал выдержки (*years*, окна потребления вроде «drink through 2020»). **Понижают:** *simple, easy, fruity, sour*, отрицания.
- **Вклад полей входа** для модели с метаданными: на описание приходится 62% влияния на прогноз оценки, но только 34% для цены. Для цены главное — регион, сорт, страна и винодельня.
- **Модель тянет прогноз к среднему:** завышает вина на 80 баллов (+1.9) и занижает вина на 97–100 (на 2.5–4 балла). Поэтому класс 95–100 распознаётся меньше чем в половине случаев.
- **Метаданные сильнее всего помогают** для дегустаторов с собственной шкалой оценок.
- **Худшие ошибки:** десертные вина и отзывы, где сомелье критикует молодое вино, но ставит высокий балл за потенциал.
